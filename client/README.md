# نرم‌افزار اندروید — Hachi Smart DNS

کلاینت اندروید سرویس اسمارت DNS هاچی (WebView، پکیج `ir.hachitech.dns`).

## استفاده (راحت‌ترین راه)

1. فایل `hachi-dns.apk` را نصب کنید.
2. **آدرس سرور** را که ادمین به شما داده وارد کنید (مثل `http://SERVER_IP:8792`) و ذخیره را بزنید.
3. کد یوزر را وارد کنید و **استارت** را بزنید.

برنامه VPN نیست و ترافیک را رد نمی‌کند؛ فقط آی‌پی خانه را به سرور خبر می‌دهد تا توی لیست سفید برود. باید روی همان وای‌فای خانه باز شود، نه اینترنت موبایل.

## ساخت از سورس

به JDK 17 و Android SDK (build-tools 34.0.0 و platform android-34) و یک debug keystore نیاز دارید؛ مسیرها را در `build.sh` درست کنید (`JDK`، `BT`، `AJAR`، `KS`) و بعد:

```bash
bash build.sh
```

خروجی: `hachi-dns.apk`.
