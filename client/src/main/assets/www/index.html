📖 آموزش ست‌کردن DNS در کنسول

اول در برنامه استارت بزنید تا آی‌پی خانه‌تان ثبت شود، بعد این قدم‌ها را در پلی‌استیشن انجام دهید:

۱

در پلی‌استیشن بروید به Settings و بعد Network و بعد Set Up Internet Connection.

۲

وای‌فای خانه را انتخاب کنید، بعد Custom را بزنید.

۳

IP Address Settings را روی Automatic و DHCP Host Name را روی Do Not Specify بگذارید.

۴

DNS Settings را روی Manual بگذارید و Primary و Secondary را هر دو عدد زیر وارد کنید.

۵

MTU روی Automatic، Proxy Server روی Do Not Use، بعد Test را بزنید.

۶

بعد از ست‌کردن، کنسول را کامل خاموش و روشن کنید (نه Rest Mode).

⛔ Secondary را هرگز به 8.8.8.8 برنگردانید؛ هر دو DNS باید همان آدرسی باشد که ادمین داده است.
